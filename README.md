# 松村優のポケモン・ワールド

企業サイトのトップページです。単一の `index.html` で構成された静的サイトで、ビルドや依存パッケージのインストールは不要です。

## ブラウザで開く手順

1. このリポジトリをクローンまたはダウンロードします。
2. `index.html` をブラウザ（Chrome、Edge、Safari など）にドラッグ＆ドロップするか、ダブルクリックで開きます。

コマンドラインから開く場合は、リポジトリのルートで以下を実行します。

```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```
